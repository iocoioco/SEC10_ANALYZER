1) 공통 시각 부호(프리미티브)

색(Color): Hue, 채도, 명도, 투명도(Alpha)

두께(Stroke Width): 0.5px ~ 4px

선형식(Line Style): 실선, 점선(- - -), 점점선(· · ·), 장단 점선(— · —)

끝/모서리(Cap/Join): butt/round/square, miter/round/bevel

채움(Fill): 단색, 그라데이션, 해치(Hatch)(////), 점, 텍스처

음영/광택: 그림자, 글로우(outer/inner)

움직임: 깜박임, 펄스(확대/수축), 천천한 이동(heatmap scroll)

아이콘/모양: ● ▲ ▼ ◆ ■ ★, 핀, 화살표, 플래그

Enclosure(둘러싸기): 테두리 박스, 하이라이트 링, 배경 음영

레이어(z-index): price > 신호마커 > 문자 > 보조선 > 배경

2) Chart Area(차트 영역) 표시 방법

배경: 단색/그라데이션/해치(저휘도)

테두리: 색/두께/모서리 둥글게

그리드: x/y 보조선 간격, 색/알파(10~20%), 점선 권장

스케일/축: 좌/우 축 분리, 가격축 배경 음영, 라벨 폰트 크기/색

참조선: VWAP, 일중 평균가, 전일종가, 평단가, 손절/익절 라인

스타일: 얇은 회색/점선, 텍스트 라벨 붙이기

영역 밴드:

런치타임/장마감 근처 시간대 스트립(strip lines)

볼린저/신뢰구간: 반투명 밴드

PIP/Inset: 우상단에 코스닥 미니, 혹은 상관지수 미니

멀티축 동기화: 가격(좌), 누적수급(우), 거래량(하단 오버레이)

3) Series/Line(선) 스타일

가격: 굵기 2~3, 진빨강, 코너는 round, 작은 그림자(가독↑)

외+프로 누적: 파랑(기본), 상승구간은 채우기(아래 half fill)

기관 누적: 초록, 음수 구간은 점선 전환

거래량지수: 회색 얇은 선 + 0축 기준 밴드

배수차(매수-매도): 보라 음영 밴드(채널 형태, 숫자 대신 면적으로)

동조도/지속성: 시안 얇은 선(=배경신호)

Spread 히스토리: 작게 점선(투명 50%)

4) Annotation(주석) 종류

포인트 마커: 전환(● 파랑), 피로(× 주황), 급체결(◆ 회색)

콜아웃(Callout): 말풍선/화살표로 특정 봉 설명

배지(Badge): “체결강도 150↑”, “피로 72” 작은 라운드칩

영역 하이라이트: 구간 반투명 박스(피로/매물대)

라벨: 라인 끝/최댓값/평단가에 붙는 짧은 텍스트

룰러/측정: 두 지점 드래그 → %·틱·시간 표시

툴팁: 호버 시 상세(숫자 다량)만 띄우기

스파크바: 주석 박스 내부에 작은 막대(최근 30초 체결강도)

5) Order Book / BookBid(호가) 시각화

구성 블록

Price Ladder: 10호가/5호가 표(행 강조)

잔량 바(Bar-in-cell): 각 호가 셀 내부에 수평 막대(좌=bid, 우=ask)

누적(Depth): 상위 5/10 누적 막대(진한색→옅은색 그라데이션)

불균형(OB Imbalance): 좌우 합의 % 막대(−100~+100)

스프레드 배지: 중앙에 1.0틱/2.8틱(주의) 칩

Cliff/슬랩: +3틱/−3틱 누적 대비 경고 아이콘(벽 얇음)

Sweep Risk: 최근 10초 단일체결/2틱잔량 비율 → 삼각표시

체결흔적(Tape): 최근 시장가 체결을 얇은 세로 히트맵으로 우측에 스크롤

가격 하이라이트: 현재가 행 배경 강조, 가격 이동 시 200ms 페이드

색 규칙: Bid=파랑, Ask=빨강, 중립=회색(저채도)

6) Alert/State(상태별 스타일 가이드)

강세 진행: 가격선 진빨강 + 외/프로 파랑 ↑, HUD Flow 파랑 배경

반전 경고: 피로도 70↑ → 차트 상단 주황 띠, 배지 점등

급변 위험: Spread ≥3틱 또는 SweepRisk ≥1.0 → 빨강 테두리 점멸

저유동성: 배경 약한 해치 /// + 호가셀 텍스트 회색화

관망: 모든 색 저채도 + 애니메이션 정지

7) 상단 HUD(권장 5개)

Flow(외+프로 순매수비율)

Tape(체결강도%)

OB(호가불균형%)

Spread(평균틱)

Fatigue(지속성 피로 0~100)

각 값은 색/아이콘/막대 3중 부호로 중복 표기(색각보정 겸용).

8) 상호작용(Interaction)

클릭: 해당 미니차트 → 호가창 동기화

호버: 300~500ms 지연 후 툴팁/확대

핀(Pin): 종목 우측 상단 핀 아이콘 → 상단 고정

키보드: F1~F6(보조판), Space(Auto 멈춤/재개), A(Auto on/off)

줌/팬: 휠/드래그, 더블클릭 원복

9) 접근성/가독성

색약 안전 팔레트(파랑/주황/보라/초록 조합)

중요 신호는 위치·모양·텍스처로도 중복 인코딩

폰트 11~12pt(숫자), 9pt(보조), 배경 대비 7:1 이상

10) 신호→스타일 매핑(권장)
신호	스타일
외+프로 전환	파랑 ● 마커 + 툴팁
체결강도 150↑	가격 위 ▲ 작은 아이콘 + HUD 파랑
피로 70↑	상단 주황 스트립 + × 마커
Spread ≥3틱	차트 테두리 주황/빨강, 호가 중앙 배지 “3.0틱(주의)”
OB ≥+30%	호가 우측 막대 길게(파랑), 중앙 배지 +30%
Cliff 위험	해당 측 가격열에 경고 아이콘(△)
Sweep Risk	DOM 우측 빨강 삼각 + 점멸
