대안 업체들
1. CME Group Real-Time Futures & Options Data API

제공 내용: 실시간 선물·옵션 데이터 스트림 (top-of-book 가격 + 체결 정보) 제공. 
CME Group

요금 구조: 데이터 양(GB) 기준 청구 (“$23/GB billed monthly” 등)로 비교적 비용 투명함. 
CME Group

장점: 선물 시장 공식 거래소 원본 피드 → 신뢰성 높음, 지연 낮음 가능성 높음

단점: 데이터량 기반 과금이라 “매우 빈번한 업데이트 → 데이터량 증가 → 비용 증가” 가능성 있음. 또한 호가 깊이/다단계 오더북이 필요 없다면 저가로 가능하지만 정확한 플랜 조건 확인 필요

2. SpiderRock

제공 내용: 미국 선물시장 (CME, CBOT 등) 포함한 실시간 및 히스토리 피드 제공. 
SpiderRock

장점: “실시간 피드 + 트릭(틱) 수준 및 신속한 API 연결” 언급되어 있음 (“typical latency ~1 ms or less”라고 설명됨) 
SpiderRock

단점: 가격과 플랜 세부조건이 홈페이지에 명확히 나와 있지는 않아, 네가 필요한 시장(나스닥 선물)만 커버되는지 확인 필요

3. DTN IQFeed

제공 내용: 실시간 스트리밍 및 역사 데이터 제공. futures 포함 언급됨. 
DTN

요금 구조: 기본 서비스 $105/mo (주식/선물/옵션 포함)부터 시작됨. 
DTN

장점: 비교적 저렴한 플랜으로 접근 가능

단점: “나스닥 선물 지수”(NQ) 수준의 실시간 피드가 이 기본 플랜에 포함되는지, 또는 추가 비용이 있는지 확인 필요
